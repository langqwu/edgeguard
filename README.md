# EdgeGuard · 断网可用的用电风险识别

> 面向**没有电网数据、网络不稳定**的场景（宿舍、出租屋、群租房、小商铺、老旧自管配电），
> 用**端侧 AI** 判断用电风险：**不依赖电网数据、不依赖摄像头、断网也能报警**。

本项目参加 **第十一届华为 ICT 大赛（2026-2027）中国创新赛 · 赛题1：基于华为云产品打造 AI 创新应用**。

---

## 1. 我们要解决什么问题

电动自行车室内充电是社区消防治理的核心痛点：起火后 30 秒即可充斥楼道，多数遇难者死于电池燃烧产生的剧毒气体。

现有方案各有硬伤：

| 现有方案 | 硬伤 |
| --- | --- |
| 电网公司的非侵入式识别（基于智能电表 15 分钟数据） | **依赖电网数据**，没有智能电表的场景进不去；判断在主站，**断网失效** |
| 电气安全硬件厂商（探测器 + 智能微断 + 平台） | 只能测电气参数（漏电/电弧/温度），**不识别"这是什么电器"**；按点位收费 |
| 电梯/楼道摄像头 + 视频 AI | 有**监控盲区**，涉及**隐私**，电池拆下来带回家充就失效 |

**我们的切入点**：拿不到电网数据、又装不起摄像头的场景，需要一个**便宜、断网可用、不碰隐私**的判断能力。

## 2. 我们的做法

```
插座 / 配电回路
      │  220V 电流
      ▼
[PZEM-004T 电能计量模块]  ← 采电压、电流、功率、功率因数（Modbus-RTU）
      │  USB / 串口
      ▼
[端侧推理]  ← 本地跑轻量模型，判断"这是什么负载 / 风险多高"
      ├──→ 本地告警（断网也有效）      ← 核心卖点
      └──→ 有网时上传云端：留痕、看板、模型迭代
```

**三条差异化**（详见 [`docs/05-competitive.md`](docs/05-competitive.md)）：

1. **端侧在环**——判断发生在现场，不是云端；断电断网仍能本地报警。
2. **无电网数据场景**——不需要智能电表，插上就能用，分钟级部署、几十元成本。
3. **判断越界而非识别电器**——见 [`docs/09-design-decisions.md`](docs/09-design-decisions.md)：
   只识别 4 类**负载形态**（恒功率长平台 / 短时高压阻性 / 剧烈跳变 / 平稳低功率），
   再结合每个插座自己的**允许规则**（最大功率、最长时长、允许时段）判断是否越界。
   这样不必穷举电器种类，换场景只改规则、不重训模型。

## 4. 快速开始

### 4.1 环境

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
```

### 4.2 采集（需先接好 PZEM-004T）

```bash
# 列出串口
python tools/list_ports.py

# 采集 30 分钟，标签为 e_bike_charger
python -m src.collect --port COM3 --label e_bike_charger --minutes 30
```

数据落地在 `data/raw/<label>/<timestamp>.csv`。

### 4.3 分析

```bash
# 生成四类负载的功率曲线对比图
python -m src.analyze --plot

# 特征提取 + 训练基线模型 + 输出指标
python -m src.train
```

## 6. 数据与隐私

- 原始用电数据只保留在本地 `data/`（已 `.gitignore`），**不入库**。
- 采集需**告知并取得参与者同意**；只采比赛所需的电参量，不采集与比赛无关的信息。
- 公开发布的示例数据会脱敏或使用合成数据，并**明确标注来源**。

---

## 7. 安全须知（220V 实验）

- 接线**必须断电操作**，接完先验电；
- CT 互感器**只套火线（L）**，不要套零线、不要套双线；
- 所有接线端放入**带保护门**的插座盒，不裸露；
- **不在宿舍做长时间大功率负载实验**；
- 尽量使用学校实验室场地，并由有经验者陪同。
