## 1. 竞品全景（按威胁从高到低）

### 1.1 云南电网「非侵入式电动自行车入户充电智能识别」——威胁最高

来源：[云南省"人工智能+"典型案例之四（2026-08-18）](http://yndrc.yn.gov.cn/html/2026/benweidongtai_0818/28070.html)

| 维度 | 它的做法 |
| --- | --- |
| 数据源 | **电网已有的 15 分钟用电采集系统**（智能电表），零硬件改造 |
| 算法 | CNN（局部波形）+ BiLSTM（长时序）融合；无监督聚类构特征库 |
| 指标 | 50+ 台区试运行，242 户疑似，现场核实 133 户，**准确率 88%** |
| 覆盖 | 常规 2–8 小时慢充；能识别"电池拆下入户充电" |
| 成本 | 零硬件改造，单户节省百元以上 |
| 身份 | 省发改委认定的"人工智能+"典型案例，电网主导 |

**它原文承认的短板（就是我们的缝隙）**：
> "现有方案依赖硬件加装，成本高、覆盖有限……高频采样方案单户改造成本超百元……视频 AI 依赖摄像头，存在视角遮挡、隐私合规风险，且无法识别电池拆卸后带入家中充电"

## 2. 我们的位置：三块能站的短板

| 对手的短板 | 我们的位置 |
| --- | --- |
| **依赖电网数据**（没智能电表的宿舍/出租屋/小商铺进不去） | 给无电网数据场景提供识别能力 |
| **推理在云端/主站**（地下室、楼道、工地弱网断网） | **端侧推理，断网也能判断** |
| **只识别行为，不评估风险**（不回答"这块电池离起火还有多远"） | 从"行为识别"升级到"风险状态"（规划） |
| **闭源** | 开源成"低采样率识别"的可复现基座 |

### 核心优势一句话

> **不是"识别得更准"，而是"在他们进不去的场景里、在网络不通的情况下，仍然能判断"。**

### 诚实说明

这目前是**技术选择的优势**，不是**资源壁垒的优势**（电网、渠道、资质都不在我们手上）。
所以必须靠"**断网演示 + 成本对比 + 真实数据**"把它变成评委看得见的差异，否则会被当作"简化版电网方案"。

## 5. 创新性判据（防止再走偏）

### 5.1 四层判据

| 层级 | 创新在哪 | 能否用 |
| --- | --- | --- |
| **L0 功能** | 多一个 AI 按钮 | ❌ 禁用 |
| **L1 场景** | 服务过去没被服务的人 | △ 仅作补充 |
| **L2 交付物** | 交付能跑、能执行的东西 | ✅ |
| **L3 交付模式** | 改变谁生产、谁拥有、怎么收费 | ✅✅ |
| **L4 资源组织** | 重组资源，成本结构断裂下降 | ✅✅ |

### 5.2 赛题的真实要求

- 不要求"全球首创"
- 要求"**具体缝隙 + 与现有方案的差异化 + 可量化指标 + 可复现**"
- 但实际竞争线更高：**评委买单的是技术纵深，不是新点子**

### 5.3 我们踩过的坑（勿重犯）

| 坑 | 教训 |
| --- | --- |
| 语音转工单 | L0 功能层，市面产品密集 |
| 一店一应用（AI 生成应用） | 与秒哒/秒悟/吐司/AgentArts 正面撞车 |
| 算力共享、代码现代化、云手机 Agent | 均已有成熟方案 |
| 把"断网可用"误读为"永不离线" | **云端迭代是赛题核心，不能否掉** |
