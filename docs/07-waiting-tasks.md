## 2. P0-A｜装码道并留下证据（今天就能做，30 分钟）

### 2.1 为什么是 P0
- 赛题写明 **CodeArts 码道是必选工具**，且"未采用赛题要求的华为技术"可能影响资格
- 材料里需要体现"用华为云产品开发"的价值
- **零成本、零风险**，唯一代价是时间

### 2.2 关于积分的时机
- 学生认证送 4000 积分，**发放后 90 天有效**，活动截止 2026-12-31
- **认证本身可以现在做**（认证 ≠ 领积分）；领积分等开始密集开发时再点
- 即使现在领了，过期时间也在 2027-01 左右，不影响初赛（11-30）

### 2.3 具体动作
1. 安装（IDE / VS Code 插件 / 桌面端任选）：https://codearts.huaweicloud.com/download.html
2. 登录华为云账号，进入 **"限时福利" → "立即认证"** 完成学生认证
3. 用码道做一件真实的小事，例如：
   - 让它给 `src/analyze.py` 的 `extract_features` 补一段 docstring
   - 或让它生成一段画对比图的小脚本
4. **每一步截图**，存到仓库 `docs/codearts/`：
   ```
   docs/codearts/01-install.png
   docs/codearts/02-student-auth.png
   docs/codearts/03-code-generation.png
   docs/codearts/04-result.png
   ```
5. 在 `docs/codearts/README.md` 记录：做了什么、花了多久、输出是否可用

### 2.4 验收

## 3. P0-B｜拉公开数据集，提前跑通（快递延误的保底）

### 3.1 为什么
- 真实数据到货前，**先用公开数据验证"特征工程 + 模型 + 评估"这条链没写错**
- 如果快递延误或场地不批，公开数据集能保证我们**仍交得出指标**

### 3.2 候选数据集（使用前核实许可）
| 数据集 | 内容 | 备注 |
| --- | --- | --- |
| **PLAID** | 家电级电流/电压波形 | 公开、常用于 NILM |
| **UK-DALE** | 多户住宅总表 + 分表 | 采样率较高 |
| **REDD** | 多户家庭用电 | 经典数据集 |
| **REFIT** | 英国家庭用电 | 含多电器 |

> ⚠️ 使用前必须确认：许可协议、是否允许用于竞赛、是否需要引用。

### 3.3 动作
1. 选 1 个最易获取的数据集，下载**一个子集**（不要全量，够跑就行）
2. 转成我们现有 CSV 格式（`timestamp, elapsed_s, voltage, current, power, energy, frequency, power_factor`）
3. 写一个转换脚本 `tools/convert_public_dataset.py`（用码道生成）
4. 跑 `analyze --features` 和 `train --leave-one-out`
5. 在 `data/README.md` 记录：数据集名称、版本、下载日期、许可、转换方式

### 3.4 关键提醒
> **公开数据集的结果不能冒充"自采数据"的实验指标。**
> 在材料里必须分开写：公开数据 = 算法有效性验证；自采数据 = 本场景适配性验证。

## 4. P1-A｜写"本地推理 / 断网可用"演示脚本

### 4.1 为什么
"端侧判断、断网可用"是我们的核心卖点，但**它不需要开发板就能演示**：笔记本本地跑推理，断开网络照样出结果。

### 4.2 要做什么
写 `src/infer.py`：
1. 加载训练好的模型（`data/processed/models/model.joblib`）
2. 读取一段 CSV（或实时模拟），输出：
   - 识别结果（充电 / 大功率 / 正常 / 不认识）
   - 置信度
   - **判定来源：本地**
3. 屏幕打印明确提示：
   ```
   [本地推理] 未联网，判断在设备端完成
   结果：e_bike_charger（置信度 0.93）
   耗时：8 ms
   ```
4. 把每次判断写入本地日志（`data/logs/infer.jsonl`），**不联网、不上传**

### 4.3 演示用法
- 关闭 WiFi / 拔网线
- 运行脚本，仍能输出结果
- **这就是 60 秒视频里"断网可用"的那一段素材**

### 4.4 验收
- 断网状态下运行成功，耗时可测，日志有记录

## 6. P2｜落实 220V 实验场地

### 6.1 为什么优先级不低
设备到货只是"能采"的一半条件；另一半是**有没有合法、安全的场地**。
实验室申请往往要走流程，**比快递更可能卡住**。

### 6.2 动作
- 今天给指导老师发一条消息：说明要做什么实验、需要什么条件（220V 插座、有人陪同、不影响他人）
- 同步询问：能否借用电子实验室的**万用表/示波器**（可省采购项）
