## P2 · 压力测试（用怀疑者视角）

### 2.1 创新缝隙

1. **谁在做类似的事？**
   - 云南电网（15 分钟电网数据 + CNN/BiLSTM，**实测 88%**，省级典型案例）
   - 电气安全厂商如安科瑞（探测器 + 智能微断 + 云平台，上市公司）
   - 校园宿舍违规电器识别（智能断路器 + 功率阈值，已批量进校）
2. **我们的差异在哪一层？** 场景层（无电网数据的场所）+ 交付物层（端侧判断 + 云端迭代）
3. **对手明天做了同样功能，我们还剩什么？** → **只剩"成本结构"和"无电网依赖"两条**，这两条目前都还没有数据支撑。
4. **一句话**："给拿不到电网数据、装不起摄像头的场所，一个断网也能判断、只采电参量的识别能力。"
5. **是资源壁垒还是技术优势？** → **技术/成本优势**，对手跟进成本约"改软件架构"，不算高。→ **所以必须靠指标和演示把差距做出来，不能只靠说法。**

### 2.2 技术纵深

1. **真正的难点是什么？** 候选：
   - 用电曲线**跨设备、跨场景的判据不稳**（同一功率可能是充电器也可能是别的）
   - **未知设备**的拒识（开集识别）
   - 可能的**多模态互补**（声学补足低采样率电信号的信息损失）
2. **在哪一层？** 判别层（开集/少样本）为主，信号层（声电）为辅。
3. **靠什么证明？** 目前**只说得出叫什么指标，说不出目标值**——因为没数据。
4. **有对照组吗？** 设计了（仅电气 vs 融合；少样本 vs 全量），**但都还没跑**。
5. **能答"为什么这么做"吗？** 判别层能答（电器无穷 → 必须能拒识）；信号层**暂时答不好**（为什么音频能帮、什么时候帮倒忙，没有实验就说不清）。

### 2.3 可复现性

1. 数据从哪来？→ 自己采（PZEM + 借负载）。**能合法拿，但还没开始采。**
2. 关键步骤能脚本化吗？→ ✅ 采集、分析、训练、评估四个脚本已就绪，换机器能跑（依赖 `requirements.txt`）。
3. 被要求现场重跑，多久能出？→ 有数据的话 **≈10 分钟**；现在**无数据，跑不出来**。
4. 依赖不可获取的东西吗？→ 依赖"借到电瓶车充电器"与"实验室 220V 场地"。**这两项未落实，是复现链上的真实断点。**

### 2.4 目的回归（逐条核对）

| 现在在做的事 | 对应 P0"最终要拿到什么" | 对应评分维度 | 判定 |
| --- | --- | --- | --- |
| 采集框架、特征、训练脚本 | 支撑"可量化指标" | 应用价值 | ✅ 必要 |
| 竞品拆解、创新性论证 | 支撑"创新性解读" | 创新性 | ✅ 必要（已过量，应停止扩写） |
| 产品形态三档、单点成本 | 答辩才用 | 无（初赛不计分） | 🟡 储备，别再多花时间 |
| 分级处置、禁用与申诉 | 答辩才用 | 无 | 🟡 储备，已足够 |
| 声电双模与少样本方案的反复讨论 | 支撑"技术纵深" | 创新性 | ⚠️ **已讨论到位，该转成实验设计** |

> **发现：文档产出已经超过实际进展。** 这是"产物替代目的"的典型漂移信号。

### 4.2 当前最致命的假设

> **假设 H1：从 1 Hz 的功率/功率因数曲线，足以稳定区分"电瓶车充电"与"其他高功率电器"。**

**如果 H1 不成立，整个方案的方法论基础就塌了**（不是指标高低的问题，是"能不能做"的问题）。

**最小证伪动作**：
1. 借到 1 个电瓶车充电器 + 1 个电热水壶 + 1 个吹风机
2. 各采 3–5 段（合计约半天）
3. 画在同一张功率-时间图上，肉眼先看**能不能分开**
4. 用现有 `train.py` 跑一次留一验证，看**是不是显著高于随机**

**通过标准**：肉眼可分 + 留一准确率 ≥ 80%（小样本下）。
**不通过的应对**：立即提高采样率（换计量模块）或引入声学模态，而不是继续写文档。

## 三个最致命的缺口（按严重度）

### 缺口 1｜零真实数据（致命）
所有指标、演示、创新论证都建立在"数据会有的"这个预期上。
**没有数据的项目，在评委眼里等于"只有想法"。**
→ 动作：本周完成 H1 的最小验证（半天采集 + 一次训练）。

### 缺口 2｜"断网可用"的适用性未验证（逻辑裂缝）
我们选的目标场景（宿舍、出租屋、小商铺）**网络其实大多是通的**。
真正缺网的是地下室、工地、偏远地区——但我们**没有选这些场景**。
**不一致点**：卖点讲"断网"，场景却选"有网的地方"。
→ 两条修补路径（二选一或并用）：
- **改主卖点**：主打"不依赖电网数据 + 数据不出户"，"断网"作为附加能力；
- **或改场景叙述**：明确包含"地下室配电间、老旧小区自管配电、工地临电"等真弱网场所。

### 缺口 3｜CodeArts 必选工具零留痕（门槛项）
赛题明写"必选"，但我们一句"用了码道"都没有证据。
→ 动作：装码道，用它生成/改写一个现有脚本，截图存档。**成本 30 分钟，风险为零。**
