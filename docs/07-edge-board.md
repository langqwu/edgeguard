# 07 · 端侧推理板是什么、要不要买、买哪个

> 面向：团队内部（非硬件背景同学也能看懂）
> 一句话结论：**端侧推理板 = 一台没有屏幕的小电脑，专门在现场跑我们的 AI 模型。第一周不要买，用笔记本先跑通；第 3 周模型稳定后再决定买树莓派还是昇腾板。**

---

## 1. 它是什么（用一句话讲清）

**端侧推理板（Edge Inference Board）**：一块信用卡到手掌大小的电路板，上面有 CPU/GPU/NPU、内存、存储和接口（USB、网口、串口、WiFi），能装 Linux 系统、能跑程序。

通俗类比：

| 你熟悉的 | 它是 | 端侧推理板相当于 |
| --- | --- | --- |
| 手机 | 有屏幕、有电池、能装 App | 一台**没有屏幕、一直插电、只跑一个程序**的手机 |
| 笔记本 | 通用电脑 | 一台**便宜很多、小很多、功耗很低**的电脑 |
| 云服务器 | 远程的大电脑 | 把云服务器的**一小部分能力搬到现场** |

**它不是**：单片机（如 STM32）——那种跑不动 AI 模型；也不是工控机——那种又大又贵。

---

## 2. 它在我们方案里干什么

### 2.1 完整数据链路

```
插座/配电箱
   │  220V 电流流经
   ▼
[PZEM-004T 计量模块]   ← 采电压、电流、功率、功率因数（串口输出）
   │  UART / USB
   ▼
[端侧推理板]           ← 核心：本地读数据 + 本地跑模型 + 本地判断
   │  判断结果："充电器异常 / 大功率电器 / 正常"
   ├──→ 本地报警（蜂鸣器 / 指示灯 / 鸿蒙设备推送）  ← 断网时也有效
   └──→ 有网时上传云端（RDS/Redis/OBS）→ 看板、历史、模型迭代
```

### 2.2 它承担的三件事

| 职责 | 具体做什么 | 为什么必须在端侧 |
| --- | --- | --- |
| **采集** | 每秒读 PZEM 的电压/电流/功率 | 数据源就在现场，没必要绕一圈上云 |
| **推理** | 跑量化后的分类模型，判断"这是什么负载/风险多高" | 断网要能用；延迟要求毫秒级 |
| **告警** | 本地蜂鸣/闪灯/通过星闪推给附近鸿蒙设备 | 火灾场景**不能等云端回包** |

### 2.3 一句话答辩话术

> "我们的判断发生在**现场这块板子上**，不在云端。所以断网、弱网、地下室照样报警——这是电网方案和电气厂商方案做不到的，它们的判断都在主站或平台。"

## 3. 为什么"端侧"是我们的核心竞争力（不是炫技）

| 原因 | 说明 |
| --- | --- |
| **1. 断网可用** | 火灾场景下，等云端回包 = 延误；端侧 ms 级判断 |
| **2. 隐私合规** | 不传原始用电数据（可只传判断结果），比摄像头方案更易被接受 |
| **3. 成本** | 一块板 + 一个计量模块，几十到几百元，可在大量低价值点位部署 |
| **4. 差异化** | 电网方案（云南电网）判断在主站；厂商方案（安科瑞）判断在平台 → 端侧是结构性空白 |
| **5. 赛题契合** | 赛题要求体现"云上部署 + Demo"，端侧 + 云正好讲"边端云协同"的完整故事 |
| **6. 团队匹配** | 队里有嵌入式/鸿蒙经验，这是我们的强项 |

### 4.1 树莓派 vs Atlas 200I DK A2 怎么选

| 维度 | 树莓派 4B/5 | Atlas 200I DK A2 |
| --- | --- | --- |
| 上手难度 | 低（装系统→Python 跑起来） | 中高（驱动、CANN、MindSpore Lite 环境） |
| 与华为生态关联 | 弱（需自己包装叙事） | **强（昇腾 = 国产算力）** |
| 评审加分 | 一般 | **明显**（往年获奖作品大量使用昇腾） |
| 5 周内风险 | 低 | 中高 |
| 价格 | ¥400–700 | ¥1500+ |
| **适合** | 求稳、先出作品 | 有余力、想冲技术分 |

**决策规则**：
- 如果第 3 周模型已经跑通、且还有 ≥ 10 天：**买 Atlas**，为初赛后的总决赛铺路。
- 如果时间紧：**树莓派**，或者干脆用**笔记本模拟端侧**（演示时拔 WiFi），也能过初赛。

## 6. 安全红线（必须遵守）

1. **220V 接线必须断电操作**，接完用万用表验电再上电。
2. PZEM 的 **CT 互感器只套火线（L）**，不要套零线，不要同时套两根。
3. 不要裸露接线端，全部放进带保护门的插座盒/配电盒。
4. **不要在宿舍做长时间大功率负载实验**（吹风机 2000W 连续跑 30 分钟有风险）。
5. 尽量借**学校实验室场地**，请老师或有经验的同学在场。
6. 采集数据前告知参与者用途，**不做与比赛无关的数据留存**（隐私合规）。

## 7. 常见误解澄清

| 误解 | 事实 |
| --- | --- |
| "端侧板是单片机" | 不是。单片机跑不动模型；端侧板是能装 Linux 的小电脑 |
| "有了云就不需要端侧" | 云解决"存和看"，端侧解决"断网时能不能判断" |
| "端侧板越贵越好" | 不是。我们只需要跑一个很小的模型，几百元的板足够 |
| "必须用昇腾才能参赛" | 不是。赛题必选是 CodeArts 码道；昇腾是加分项，不是门票 |
| "先买板再想做什么" | 反了。先跑通数据和模型，再按算力需求选板 |

## 8. 一句话总结

> **端侧推理板 = 把 AI 的判断能力，从云端搬到现场的小盒子。**
> 它是我们"断网也能报警"这个核心卖点的物理载体，但**不是第一周该花钱的地方**——先用笔记本把数据和模型跑通，第 3 周再按需采购。
