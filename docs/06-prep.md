## 3. 软件与算法准备

### 3.1 软件栈（全部免费）

| 层 | 选型 | 说明 |
| --- | --- | --- |
| 采集 | Python + `pyserial`（PZEM 走 Modbus-RTU） | 10 分钟能出第一条数据 |
| 数据处理 | pandas + numpy + matplotlib | 画功率曲线，肉眼先找特征 |
| 模型 | 先 **scikit-learn**（特征 + 分类器），再上 **PyTorch/CNN** | 别一上来就深度学习 |
| 端侧 | ONNX → **MindSpore Lite**（若上 Atlas/鸿蒙）或 ONNX Runtime（若树莓派） | 量化压缩后部署 |
| 应用 | 后端 FastAPI/Flask + 前端（小程序或 H5） | CodeArts 生成，省时间 |
| 云端 | RDS + Redis + OBS + 告警推送 | 用 Skills 开通 |

### 3.2 初赛必须跑通的三步（全部在笔记本上完成）

**第一步：采到真实波形（卡时间，最先做）**
- 目标：拿到"电瓶车充电器 / 电热水壶 / 吹风机 / 空调（或取暖器）"各 ≥ 20 段功率曲线（每段 ≥ 30 分钟，采样 ≥ 1Hz）。
- 产出：`data/raw/*.csv` + 一张"四类负载功率曲线对比图"。
- 判定：能肉眼区分"充电器的恒功率平台"和"水壶的短时高功率"。
- 直接支撑材料里的：**数据集的选取与处理**。

**第二步：训一个小模型，出指标**
- 目标：特征（功率阶跃、平台时长、功率因数、谐波特征）+ 分类器，三分类（充电/大功率电器/正常）。
- 产出：混淆矩阵、准确率、误报率。
- 判定：在**未参与训练**的样本上准确率 ≥ 85%（先求有，再求高）。
- 直接支撑材料里的：**关键代码片段 + 可量化指标**。

**第三步：笔记本断网演示（初赛视频素材）**
- 目标：模型在笔记本本地运行，**断开网络**仍能判断并弹出告警。
- 产出：一段 60 秒屏幕录制（断网 → 插入充电器 → 1–2 秒内告警）。
- 判定：断网状态下可复现。
- 说明：这就是我们的核心卖点"端侧在环"的初赛证据，**不需要任何板子**。

> 初赛之后（12 月—3 月）再补：真实端侧板部署、RDS/Redis、可视化 Demo 页面、星闪组网、开源完善——这些是总决赛材料。

### 3.3 数据来源（三条腿走路，防止采集失败）

| 来源 | 用途 | 备注 |
| --- | --- | --- |
| **自采** | 主数据，真实感最强 | 需要充电器与负载，本周就能开始 |
| **公开数据集** | 冷启动 + 论文里引用 | NILM 领域有 PLAID、UK-DALE、REDD、REFIT 等（用前核实许可） |
| **物理仿真** | 补充极端样本 | 按"恒功率 + 阶跃 + 平台"建合成曲线，**必须标注为合成** |
