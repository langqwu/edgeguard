# 08 · 接线与采集操作手册（实物步骤）

> 面向：第一次上手 PZEM-004T 的队友。
> 目标：把"插头插哪、线怎么接、数据怎么进电脑"讲清楚。
> ⚠️ 涉及 220V，**必须断电接线、老师或实验室老师在场**。

---

## 0. 先确认你买的是哪个版本（最关键的一步）

PZEM-004T 有**两种通信版本**，外观相似但接法完全不同：

| 版本 | 板上标识 | 你需要什么 | 怎么判断 |
| --- | --- | --- | --- |
| **TTL 版**（我们要的） | 4 针排针，标 `5V / GND / TX / RX` | USB 转 TTL（CH340） | 有 4 针排针 |
| **RS485 版** | 端子标 `A / B` | USB 转 RS485 | 有 A/B 两个端子，无 4 针排针 |

> 如果买到 RS485 版，**不能直接接 USB-TTL**，需要额外买一个 USB-RS485 转换器（约 ¥20）。
> 下单前看商品图，确认是 **TTL 版（4 针）**。

**电流规格**：10A 版与 100A 版。我们买 **100A 版**（带开合式 CT），量程 0–100A，足够测电瓶车充电器（约 1–3A）和吹风机（约 8A）。

## 1. 模块上有哪些接口

```
┌─────────────────────────────────────────────┐
│  PZEM-004T v3.0                             │
│                                             │
│  [L]  [N]        ← 220V 电压测量 + 模块供电  │
│                                             │
│  [CT]  ← 电流互感器二次侧（两根细线）         │
│                                             │
│  [5V] [GND] [TX] [RX]  ← TTL 通信（4 针）    │
└─────────────────────────────────────────────┘
```

| 接口 | 作用 | 注意 |
| --- | --- | --- |
| **L、N 端子** | 接市电火线/零线，**既测电压也给模块供电** | 不接市电，模块不工作 |
| **CT 接口** | 接开合式互感器的两根线 | 有方向，接反功率为负 |
| **TTL 4 针** | 与电脑通信 | `5V` 必须接（TTL 口是"被动"的，需外部供电） |

**手册原文（Hadex）**：
> "Rozhraní TTL tohoto modulu je pasivní rozhraní, vyžaduje externí napájení 5 V… musí být připojeny všechny čtyři porty (5 V, RX, TX, GND)"
> → TTL 口需要外部 5V，且 **4 根线必须全接**，少一根就不通信。

## 2. 整体连接关系（先看懂这张图）

```
        ┌──────────── 220V 市电（实验室插座）────────────┐
        │                                              │
        │  L ────────┬──────────────────┐              │
        │            │                  │              │
        │            │              ┌───┴────┐         │
        │            │              │  负载   │         │
        │            │              │ 插座    │         │
        │            │              └───┬────┘         │
        │            │                  │              │
        │            │   ╔══════════╗   │              │
        │            │   ║ CT 夹住  ║   │              │
        │            │   ║ 这根 L 线 ║   │              │
        │            │   ╚══════════╝   │              │
        │            │                  │              │
        │            └──► PZEM 的 L      │              │
        │                               │              │
        │  N ────────┬──────────────────┘              │
        │            └──► PZEM 的 N                    │
        │                                              │
        │  PE（地线）──────► 负载插座的地线（必须接）    │
        └──────────────────────────────────────────────┘

PZEM TTL：5V ── USB-TTL 的 5V
          GND ─ USB-TTL 的 GND
          TX  ─ USB-TTL 的 RX   ← 交叉
          RX  ─ USB-TTL 的 TX   ← 交叉
USB-TTL ──► 电脑 USB ──► 串口（COMx）──► src/collect.py ──► CSV
```

**理解要点**：
- PZEM 的 L/N 与负载**并联**（测同一路电压）；
- **CT 只夹负载的那一根火线**（测这一路的电流）；
- 电脑通过 TTL 读数据，**不参与强电回路**。

## 3. 三种搭法，按安全程度选

### 方案 A（最安全，推荐）：买现成的"计量插座测试盒"

> **详细到"哪根线插哪个口"的操作说明，见 [09-option-a-testbox.md](09-option-a-testbox.md)。**

淘宝搜「PZEM-004T 测试盒 / 计量插座 外壳」，约 ¥30–60。
它已经把"插头 + 插座 + 模块 + CT"都装好了，你只需要：
1. 插头插实验室插座；
2. 负载插它面板上的插座；
3. TTL 四线接 USB-TTL，插电脑。

**优点**：不用自己碰 220V 接线，安全、省时间。

### 方案 B（推荐）：请实验室老师协助做一个测试工装

把材料拿到实验室，请老师/实验员用 10 分钟做一个"插头进、插座出、中间串 CT"的盒子。
你在旁边看清接线，之后自己只接 TTL。

### 方案 C（不推荐单独做）：自己接线

只有在老师在场、有漏电保护插座、且你完全理解第 2 节电路图时才做。

## 4. 接线步骤（按方案 C，断电状态下进行）

### 第 1 步：断电与验电
1. 拔掉实验台插座的开关（或断开空开）；
2. 用**验电笔/万用表**确认要接的线**无电**；
3. 全程不要让裸线碰到手或其他金属。

### 第 2 步：准备导线
- 用 1.5mm² 铜芯线，剪 3–4 段，每段 10–15cm；
- 剥线 8–10mm，**不要剥太长**（避免裸露过多）。

### 第 3 步：接 PZEM 的 L / N
1. 市电插头（或插排）的 **L** → PZEM **L** 端子；
2. 市电插头（或插排）的 **N** → PZEM **N** 端子；
3. 用螺丝刀拧紧，**轻拉一下确认不松**。

### 第 4 步：接负载插座与 CT
1. 负载插座的 **L** 接到市电 **L**（这一段线要**穿过 CT**）；
2. 负载插座的 **N** 接到市电 **N**；
3. 负载插座的 **PE（地）** 接到市电 **PE**（地线必须接，不可省）；
4. **CT 夹在去负载的 L 线上**：
   - 只夹**一根**线（不要同时夹 L+N）；
   - 注意 CT 上的**箭头方向**，箭头指向负载；
   - 开合面扣紧，听到"咔"一声。

### 第 5 步：接 CT 到模块
- CT 的两根细线插进模块的 **CT 接口**（小白色插座），插到底。

### 第 6 步：接 TTL（断电状态下接好，避免带电插拔）
| PZEM 针脚 | USB-TTL 针脚 | 说明 |
| --- | --- | --- |
| 5V | 5V | 给 TTL 侧供电（**必须接**） |
| GND | GND | 共地 |
| TX | **RX** | 交叉 |
| RX | **TX** | 交叉 |

> USB-TTL 板上如果有 3.3V/5V 跳线或开关，**必须选 5V**。

### 第 7 步：检查与上电
1. 再检查一遍 L/N 没有接反、没有短路（L 与 N 不能碰在一起）；
2. 接线端**用绝缘胶带包好**或放进插座盒；
3. 上电，观察模块上的**指示灯是否亮**（不亮 = 没供电或 L/N 没接好）；
4. 上电后**不要用手碰任何接线端**。

## 5. 数据怎么进电脑（传输链路）

### 4.1 物理链路
```
PZEM（TTL）── 4 根杜邦线 ── USB-TTL ── USB 线 ── 电脑
```
电脑上会出现一个**串口**（Windows：`COM3`、`COM4`…）。

### 4.2 查串口
```bash
python -m tools.list_ports
```
输出里找 `USB-SERIAL CH340` 对应的 `COMx`。

### 4.3 探测地址（第一次必做）
模块**出厂地址可能是 `0xF8`，也可能是 `0x01`**（不同批次不同）。先探测：
```bash
python -m tools.pzem_probe --port COM3
```
- 命中会打印：`命中 0xF8：U=220.1V I=0.000A P=0.0W ...`
- 全部不中，按提示排查（接线、5V、市电、串口占用）。

### 4.4 开始采集
```bash
python -m src.collect --port COM3 --label e_bike_charger --minutes 30 --plot
```
- `--label`：负载标签（`e_bike_charger` / `kettle` / `hair_dryer` / `normal`）
- `--minutes`：采集时长
- `--plot`：实时看功率曲线（可选）
- 地址不用管，程序会自动探测

数据落在：`data/raw/<label>/<时间戳>.csv`，同时生成 `.meta.json`。

### 4.5 CSV 长什么样
| timestamp | elapsed_s | voltage | current | power | energy | frequency | power_factor |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 2026-10-25T10:00:00Z | 0 | 220.1 | 1.234 | 271.4 | 0.0001 | 50.0 | 0.62 |

## 6. 采集时的注意点

| 事项 | 要求 |
| --- | --- |
| 采样间隔 | 1 秒（默认），全程稳定 |
| 单段时长 | 充电器 60–180 分钟；水壶 8–10 分钟；吹风机 8–12 分钟；正常 20–60 分钟 |
| 标签 | 严格用四个约定名，**不要自创** |
| 环境记录 | 记下插座位置、室温、设备型号（写进 `data/README.md`） |
| 不中断 | 采集过程中不要插拔 TTL 线（会丢数据/损坏串口） |
| 负载切换 | 换负载前**先停止采集**，再拔插头 |

## 7. 故障排查

| 现象 | 可能原因 | 处理 |
| --- | --- | --- |
| `pzem_probe` 全部不中 | TTL 只接了两根（TX/RX），没接 5V/GND | 按第 6 步把 4 根接全 |
| | USB-TTL 跳线在 3.3V | 切到 5V |
| | L/N 没接市电（模块没供电） | 接好 220V，看指示灯 |
| | 串口被其他软件占用 | 关掉串口助手/其他脚本 |
| | 买成 **RS485 版** | 换 USB-RS485 转换器 |
| 读到的功率是 **负数** | CT 方向反了 | 把 CT 反过来夹，或箭头朝负载 |
| 功率为 **0**，电流为 0 | 负载没插在这个回路 / CT 没夹住 L 线 | 检查负载插座是否由这段 L 供电 |
| 读数是 0 但电压正常 | 负载功率太小（低于启动阈值 0.4W / 0.02A） | 换大一点的负载测试 |
| 数据乱码/CRC 错 | 波特率不对（应 9600 8N1）或线太长 | 检查线材，缩短杜邦线 |
| 电脑识别不到串口 | CH340 驱动没装 | 装驱动，设备管理器看 COM 号 |

## 8. 安全红线（贴在实验台上）

1. **断电接线、接完验电、再上电**；全程不要用手碰裸露端子。
2. **L 与 N 绝不能碰在一起**（短路会跳闸甚至起火）。
3. **CT 只夹一根线**，不要夹两根。
4. **地线（PE）必须接**，不能省。
5. 使用**带漏电保护**的插座；有老师在場。
6. 上电后**不要插拔 TTL 线**，要改接线先断电。
7. PZEM v3 的 UART 是**光耦隔离**的（手册标注），但**仿品/不同批次不保证**，仍按带电设备对待：笔记本尽量拔掉充电器用电池，不要触碰电路板。
8. 大功率负载（吹风机 2kW）**不要连续跑太久**，中间留散热时间。

## 9. 一页纸操作卡（可打印）

```
【上电前】
□ 断电、验电
□ L→L、N→N，地线接好
□ CT 只夹负载 L 线，箭头朝负载，扣紧
□ CT 两根线插进模块 CT 口
□ TTL：5V-5V、GND-GND、TX-RX、RX-TX（4 根全接）
□ USB-TTL 跳线在 5V
□ 接线端包好绝缘

【上电后】
□ 模块指示灯亮
□ python -m tools.list_ports         → 找到 COMx
□ python -m tools.pzem_probe --port COMx  → 命中地址
□ python -m src.collect --port COMx --label <标签> --minutes <时长>
□ 检查 data/raw/<标签>/ 下有 CSV

【收工】
□ 先停采集（Ctrl+C）
□ 再断电
□ 记录 data/README.md（日期/环境/设备/时长）
```
