# 12 · 技术纵深评估：我们够不够"有技术含量"

> 起因：队友质疑"我们的方案是不是太简单了，往年作品看着都很有技术含量"。
> 结论：**确实偏简单**。当前"14 个特征 + 随机森林三分类"属于课程设计水平。
> 但问题不在场景，而在**我们还没在任何一层扎下去**。本文给出四条加深路径与取舍建议。

---

## 1. 先把差距摆到桌面上

| 往届作品 | 技术核心 | 难度来源 |
| --- | --- | --- |
| ModelEngine ViT 推理优化（国一） | 昇腾上的性能工程：ONNX/OM 转换、H2D 搬运、异步流水线、WSI 切块聚合 | 硬件特性理解 + 系统级调优 |
| AscendSentinel（全球二） | 音频 + 毫米波雷达点云**多模态融合**，边端云协同 | 传感器融合 + 实时性 |
| MindAligner（国二） | 自研 EEGAlignNet + 小样本/跨个体泛化 + 论文软著 | 算法原创 + 医学数据 |
| U-care Yuka（国二） | 端侧 VLA 模型 + SLAM + 机械臂 | 具身智能集成 |
| 病理问答智能体（国一） | 大模型轻量化微调 + 多模态 + RAG | 专业领域微调 + 评测 |

**我们当前**：PZEM 采 1 Hz 功率 → 14 个统计特征 → 随机森林三分类。

**评价**：这是一份合格的课程作业，不是竞赛级工作。**评委 30 秒就能看出来。**

---

## 2. 但"加深"不等于"加模块"

常见错误：堆 CNN + LSTM + Transformer + 注意力，却说不清每个模块解决什么问题。

正确做法：**在某一层真正扎下去，并把"为什么难、怎么解决、效果如何"讲透。**

技术栈是有层次的，任选一层加深都能形成纵深：

| 层级 | 我们现在 | 可加深方向 |
| --- | --- | --- |
| **信号层** | 1 Hz 功率、功率因数 | 电流波形、谐波、纹波、瞬态 |
| **特征层** | 14 个统计量 | 曲线形态学、变点检测、频域特征 |
| **判别层** | 有监督三分类 | **少样本、开集识别、环境自适应** |
| **决策层** | 分类结果 | 越界规则引擎 + 置信度 + 拒识 |

---

## 3. 四条加深路径

### 路径 A：声电双模融合 ⭐ 推荐

**做法**
- PZEM 采低频电参量（1 Hz）
- 手机/麦克风同步录音（16 kHz 以上，能到 48 kHz 更好）
- 两路信号做**特征级或决策级融合**，做负载识别

**技术难点（这些就是"技术含量"）**
1. **时间对齐**：音频与功率采样率差 2–3 个数量级，怎么对齐到同一时间窗
2. **噪声与混响**：实验室/宿舍环境噪声大，怎么抑制
3. **声学特征选择**：MFCC、频谱质心、过零率、高频能量占比
4. **模态互补性分析**：什么情况下音频有用、什么情况下帮倒忙

**为什么这条最有说服力**
- 与 AscendSentinel 同属"多模态融合"，路数被验证过
- 能给出**单模 vs 双模**的对比指标，增益本身就是结论
- 成本近乎为零（手机可录）
- 有真实可讲的物理依据：电热水壶沸腾声、吹风机电机啸叫、开关电源的高频啸叫（几 kHz）、继电器吸合声

**指标**
| 指标 | 说明 |
| --- | --- |
| 单模态（仅电气）准确率 | 基线 |
| 单模态（仅音频）准确率 | 对照 |
| 融合后准确率 | 主结果 |
| 融合增益 | 融合 − 最优单模 |
| 噪声条件下退化幅度 | 加背景噪声（如宿舍对话）后的表现 |

**风险**：需要有人愿意碰音频处理；录音设备一致性要控制（最好固定同一台手机）。

---

### 路径 B：少样本与未知设备泛化 ⭐ 稳妥，改动最小

**做法**
- 每类设备只用 3–5 个样本训练
- 测试集包含**训练时完全没见过的电器**
- 报"未知设备拒识率"与"开集识别"表现

**技术难点**
1. **开集识别**：模型不仅要分类，还要会说"我不认识"
2. **特征的可迁移性**：哪些特征对未见设备仍有效
3. **阈值设定**：拒识阈值太低误报多、太高漏报多

**为什么值得做**
- 这是 NILM 领域公认的真难题（电器无穷无尽）
- **不增加任何硬件与成本，只改变实验设计**
- 能把"课程设计"立刻提升为"有研究性的工作"

**指标**
| 指标 | 说明 |
| --- | --- |
| few-shot（3/5 样本）准确率 | 少样本能力 |
| 未知设备拒识率 | 正确说"不认识"的比例 |
| 未知设备误分类率 | 把新设备错分成已知类的比例 |
| 开集 F1 | 综合指标 |

**风险**：需要真的采到"未见设备"样本（相对容易：多借几样电器）。

---

### 路径 C：充电曲线判电池类型/健康度（有想象力，风险高）

**做法**
从充电曲线的**恒流段斜率、恒压段持续时长、结束行为、纹波幅度**判别：
- 铅酸 vs 锂电
- 48 V vs 60 V 电池组
- 老化程度（内阻增大 → 恒压段变长）

**技术难点**
- 充电曲线阶段切分（CV/CC 转换点检测）
- 小样本下的健康度回归
- 需要真实的老化/改装电池样本

**风险**
- **样本获取难**：老化电池、改装电池不容易搞到
- **验证难**：没有标准答案（除非能找到电池规格书对照）
- 做不深就会退化成"又一个阈值判断"

**建议**：作为"未来工作"写在方案里，**不作为主实验**。

---

### 路径 D：极限压缩与端侧部署（工程纵深）

**做法**：把模型量化压到几十 KB，在 MCU / 开发板上跑，绘制"压缩率 vs 精度损失"曲线。

**技术含量**：真实的工程权衡问题，且与产品形态（嵌进插座）直接对应。

**问题**：**初赛没有板子，无法实测**，只能纸上谈兵。

**建议**：归入档 B（初赛通过后做）。

## 4. 四条路径对比

| 路径 | 技术含量 | 成本 | 初赛可完成 | 风险 | 推荐 |
| --- | --- | --- | --- | --- | --- |
| **A 声电双模** | ★★★★★ | 极低（手机） | ✅ | 中（需人碰音频） | ✅✅ **强烈推荐** |
| **B 少样本/未知泛化** | ★★★★☆ | 零 | ✅ | 低 | ✅✅ **必做** |
| C 电池健康 | ★★★★☆ | 中 | ⚠️ 勉强 | 高（样本） | ❌ 仅写"未来工作" |
| D 极限压缩 | ★★★★☆ | 中 | ❌ 需板子 | 中 | ⏳ 决赛再做 |

---

## 5. 建议的初赛组合

> **必做：路径 B** —— 不改硬件、不加成本，只改实验设计，立刻提升研究性。
>
> **强烈建议：路径 A** —— 如果有人愿意碰音频，这是答辩时最容易被记住的点，也是唯一能对标 AscendSentinel 的技术叙事。
>
> **不做：路径 C、D**。

### 组合后的方案叙事（答辩版）

> "我们不把这件事当成一个分类问题，而是当成两个更难的问题：
> 第一，**设备是无穷无尽的**，所以模型必须能识别'我不认识'（路径 B）；
> 第二，**只靠电信号信息不足**，所以我们引入声学模态（路径 A）。
> 我们报告的不是一个准确率，而是**少样本下的泛化**与**多模态的增益**。"

这段话一出来，层次就和"我们训了个随机森林"完全不同。

---

## 6. 一条警戒线

**不要为了显得有技术含量而堆方法。**

评委见过太多"CNN + LSTM + Transformer + 注意力机制"却说不清为什么的作品。

如果做路径 A，你必须能回答：
- "为什么音频能提升识别？"
- "什么情况下音频反而帮倒忙？"
- "融合是在特征级还是决策级？为什么？"

**能答上来 = 技术含量；答不上来 = 堆料。**

## 7. 对现有计划的影响

| 影响项 | 变化 |
| --- | --- |
| 数据采集 | 每段采集时**同步录音**（手机即可），文件与 CSV 同名 |
| 特征工程 | 增加音频特征（MFCC / 频谱质心 / 高频能量） |
| 实验设计 | 增加"少样本"与"未知设备"两组实验 |
| 指标表 | 增加融合增益、拒识率、开集 F1 |
| 设备采购 | **不变**（不需要新硬件） |
| 时间 | 路径 B 约 +2 天；路径 A 约 +3–4 天（可并行） |

> 五周计划仍成立：把"声电双模"放进 W2 采集阶段（录的时候顺手录），
> 把"少样本/未知设备"放进 W3 实验设计。

---

## 8. 结论

**技术含量不是靠"做更多功能"，而是靠"把一个问题做深"。**

我们不需要变成五个往届作品的合集，只需要：
- 选 **1–2 个**真正的难点
- 把"为什么难、我们怎么解决、效果如何"讲清楚
- 给出别人没给过的数字

这就够了。
