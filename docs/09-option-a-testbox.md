# 09 · 方案 A 详解：买现成"计量插座/测试盒"怎么用

> 目的：把"哪个设备的哪根线插到哪个口"讲到不用猜。
> 前提：方案 A = 买一个**已经把 PZEM 模块、CT、插座装好**的盒子，你不碰 220V 接线。

---

## 一、先分清你买到的是哪一种（决定后面怎么接）

市面上的"PZEM 计量插座/测试盒"有三类，**外观都是个盒子，但引出方式不同**：

| 类型 | 盒子外面能看到 | 你要做什么 | 难度 |
| --- | --- | --- | --- |
| **A1 成品（内置 USB）** | 面板上有**一个 USB 口**（方口/Micro/Type-C） | 一根 USB 线连电脑即可 | ★ 最简单 |
| **A2 半成品（引出排针）** | 面板/侧面有 **4 根排针**，标 `5V GND TX RX` | 用杜邦线接 USB-TTL，再连电脑 | ★★ |
| **A3 空壳/外壳** | 只有盒子、没有模块，或模块要自己装 | 等于自己接线，回到方案 C | ★★★★ 不推荐 |

**怎么快速判断**：拿到手先看盒子表面——
- 有 USB 口 → **A1**
- 有 4 针排针 → **A2**
- 只有插头+插座、没有通信口 → 你买成了 A3（空壳），需要另配模块和接线

> ⚠️ 还有一种"错版"：盒子引出的是 **RS485 的 A/B 两个端子**（不是 4 针 TTL）。
> 那需要 **USB 转 RS485** 转换器，不能接 USB-TTL。

---

## 二、A1（内置 USB）怎么接——只有 3 个动作

这是最省事的情况。

```
① 盒子电源插头  →  实验室墙插（220V）
② 负载插头      →  盒子面板上的输出插座
③ USB 线        →  一头插盒子 USB 口，一头插电脑 USB 口
```

### 按顺序做

| 步骤 | 手上动作 | 检查点 |
| --- | --- | --- |
| 1 | 把盒子的**电源插头**（公头，三脚）插进实验室墙插 | 盒子指示灯亮 |
| 2 | 电脑上插好 USB 线（先别插负载） | 设备管理器出现 `USB-SERIAL CH340 (COMx)` |
| 3 | 跑 `python -m tools.pzem_probe --port COMx` | 应读到 `U≈220V，P≈0W` |
| 4 | 把**负载的插头**插进盒子面板的**输出插座**（母座，五孔） | 功率从 0 跳到实际值 |
| 5 | 跑采集命令 | CSV 里有数据 |

**关键理解**：盒子只测"插在它输出插座上的那个负载"。插在别处（比如同一个插排的另一个孔）不会被测到。

### A1 的接线示意

```
      实验室墙插（220V）
            ▲
            │ 盒子电源插头（公头）
      ┌─────┴──────────────┐
      │   计量测试盒         │
      │  ┌──────────────┐  │
      │  │ PZEM + CT    │  │
      │  └──────────────┘  │
      │   输出插座（母座）   │◄── 负载插头（充电器/水壶）
      │   USB 口            │◄── USB 线 ──► 电脑
      └────────────────────┘
```

## 三、A2（引出 4 针排针）怎么接——多一步杜邦线

```
① 盒子电源插头 → 墙插（220V）
② 负载插头     → 盒子输出插座
③ 杜邦线 4 根  → 盒子排针 ↔ USB-TTL
④ USB-TTL      → 电脑 USB
```

### 杜邦线接法（核心，就这张表）

| 盒子排针 | USB-TTL 针脚 | 线色建议 | 说明 |
| --- | --- | --- | --- |
| **5V** | 5V | 红 | 给 TTL 侧供电，**必须接** |
| **GND** | GND | 黑 | 共地 |
| **TX** | **RX** | 白 | **交叉** |
| **RX** | **TX** | 绿 | **交叉** |

> **TX/RX 必须交叉**：盒子的"发"接转换器的"收"。
> **4 根线必须全接**：手册明确写"TTL 口是被动的，需外部 5V，四个端口缺一不可"。

### A2 的接线示意

```
      实验室墙插（220V）
            ▲
            │ 盒子电源插头
      ┌─────┴──────────────┐
      │   测试盒             │
      │   输出插座（母座）   │◄── 负载插头
      │   排针: 5V GND TX RX │
      └───────┬─────────────┘
              │ 杜邦线（4 根，TX/RX 交叉）
      ┌───────┴─────────────┐
      │   USB 转 TTL（CH340）│
      └───────┬─────────────┘
              │ USB 线
           电脑（COMx）
```

### 顺序注意
1. **先在盒子断电（拔掉墙插）时接好杜邦线**，再上电；
2. USB-TTL 板上若有 3.3V/5V 跳线，**选 5V**；
3. 上电后再插 USB（或先插 USB 再上电都行，但**不要在通电时拔插杜邦线**）。

## 四、A3（空壳）怎么办

如果买到的只是外壳：
- 需要另买 **PZEM 模块 + CT**，装进盒子，按方案 C 接线；
- 或者直接放弃盒子，请实验室老师做一个工装（方案 B）。

---

## 五、买之前跟卖家确认这 5 件事

| # | 问卖家 | 为什么 |
| --- | --- | --- |
| 1 | 是否**包含 PZEM-004T 模块**？ | 避免只买到空壳 |
| 2 | 通信是 **TTL 4 针**还是 **RS485**？ | 决定配 USB-TTL 还是 USB-RS485 |
| 3 | 是否**内置 CH340**（面板有 USB 口）？ | 有的话最省事（A1） |
| 4 | 插座是 **10A 还是 16A**？ | 测水壶/吹风机（8–9A）建议 16A |
| 5 | 是否**带开关**？ | 方便通断，不用每次拔插头 |

---

## 六、到货后 5 分钟验收（不接负载先测）

| 步 | 动作 | 期望 |
| --- | --- | --- |
| 1 | 盒子插墙，观察指示灯 | 灯亮 |
| 2 | USB 接电脑，查串口 | 出现 CH340 的 COMx |
| 3 | `python -m tools.pzem_probe --port COMx` | 读到电压 ≈220V，功率 ≈0W |
| 4 | 插一个 5W 手机充电器 | 功率跳到 4–6W |
| 5 | 拔掉，功率回 0 | 数据正常 |

> 第 3 步读不到，先看串口是否被占用、盒子是否上电、杜邦线是否接全。

## 七、常见问题（按方案 A 场景）

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 盒子灯不亮 | 墙插没电 / 插头没插到底 | 换插座、插紧 |
| 电脑没有 COM 口 | CH340 驱动未装 | 装驱动；设备管理器看"未知设备" |
| 有 COM 口但探测无响应 | 盒子是 RS485 版 | 换 USB-RS485 |
| | 杜邦线 TX/RX 没交叉 | 对调 TX/RX |
| | 只接了 TX/RX，没接 5V/GND | 四根接全 |
| 电压正常但功率一直是 0 | 负载没插在盒子输出插座上 | 插到盒子的输出口 |
| 功率为负 | CT 装反（盒子内部） | 联系卖家或拆开反接 CT（不建议自行拆） |
| 测水壶时盒子发烫 | 盒子 10A 规格，接近极限 | 缩短测量时间，或换 16A 盒子 |

---

## 八、安全提醒（方案 A 也不能大意）

1. 盒子必须**插在有漏电保护的墙插**上；
2. 手不要碰盒子的**输出插座内部**和任何裸露端子；
3. 插拔负载前，**先关掉盒子/插排开关**（有开关的话）；
4. 测完先拔负载，再拔盒子电源；
5. 盒子发烫、有异味、有"滋滋"声 → **立即断电并停止使用**；
6. 220V 操作全程有老师或实验员在场。

---

## 九、方案 A 一句话总结

> **盒子的公头插墙，负载的插头插盒子的母座，USB 线（或 4 根杜邦线）接电脑。**
> 盒子只测"插在它输出口上"的那一个负载；电脑只碰 TTL/USB 低压侧。
